# Park to Podium

Park to Podium is a strategy management game where the player develops their own disc golf park.

The game starts with a simple area in nature and gradually builds:
- disc golf holes
- clubhouse
- practice area
- shop
- workshop
- tournament center
- parking lot
- camping
- sponsors

Players can collect resources, upgrade the park, train players and host tournaments.
Course attributes affect tournament results.

Further down the line, the project aims to include:
- Visit other players parks
- Leaderboards
- Weekly challenges
- Clubs
- Seasons
- Community functions

The project is currently in the planning phase.
